# Drug Classification – ML CI/CD Demo

A browser-side drug classification app built with ONNX Runtime Web.

- Model trained with Scikit-learn (Random Forest) and exported to ONNX.
- CI/CD pipeline powered by GitHub Actions and CML.
- Inference runs entirely in the browser — no server required.

**Educational demonstration only. Not a medical decision tool.**
